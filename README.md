# Code Themes

Three dark animated themes for Claude Code (desktop and mobile apps).

- **Ash Snow** (recommended): charcoal sky, moon, snow, a hiker with a lantern
- **Blue Steel**: blue-grey ridges, shooting stars, birds
- **Cyberpunk**: soft pink and teal night city

## Install

```bash
claude plugin install ash-snow --marketplace grizz6/code-themes
```

Choose the **user** scope. Swap `ash-snow` for `blue-steel` or `cyberpunk`. Install one theme at a time.
